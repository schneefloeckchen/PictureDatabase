Sie auch BertaLogBuch zum git-setup.

  1. In Konsole: git init f. lokales repo, setze branch namen auf development.
  2. in NB: commit
  3. auf ..speicher/scw/git/PictureDatabase mit init ein remote repo erzeugt
  4. Im Dev Verzeichnis mit git remote add berta /home/rene/speicher/.. das neue repo als berta angebunden
  5. git push berta development, den stand ins repo gepushed. Daten dort im unsichtbaren Verzeichnis .git
